## 主要结论

- 4B v2 在 87 条本仓库路由题上为 82/87，优于首轮 v1 的 71/87。该题集已参与迭代；稳定性与新仓库结果单独见第 03 篇。
- 检索结果受切块、分词和评测语料影响。旧索引与排除考题后的索引分别记录，阈值不能跨索引直接沿用。
- 干净索引上的 90 题中，两条链路均被自动评委判正确 81 题。Q4 链路平均耗时和回答侧 API 费用较低；一次运行及自动评分不足以证明质量等价。
- 人工盲评只覆盖第一轮的 21 题、42 份答案，不能当作全量 90 题的人工准确率。
