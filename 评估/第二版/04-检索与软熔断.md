# 检索与软熔断评测

分别记录旧索引检索、中文分词复测、软熔断标定与排除考题文件后的复测。

[返回目录](README.md) · [上一章：路由微调](03-路由微调.md) · [下一章：量化与系统接入](05-量化与系统接入.md)

## 1. 实验设置

- 知识库来自 `src/`，比较字符 / AST 切块与标准 / Flash 嵌入；嵌入模型为 `qwen3.7-text-embedding` 和 `qwen3.7-text-embedding-flash`。
- 字符索引 87 块，平均 1259 字符；AST 索引 110 块，平均 916 字符。旧索引包含评测源码，后续干净索引另列。
- 检索使用 18 题、Top-8：精确关键词 5、中文语义 5、英文语义 3、中英混合 5。Hit@8 按预期来源文件命中计分，MRR 衡量首个命中文件的排名。
- 软熔断使用 90 题：域内 40、域外 50。强制 Dense Top-1，不经过路由；距离严格大于阈值时拦截，在域内误伤不超过 3/40 的约束下选择阈值。

## 2. 旧索引检索结果

每格为 **Hit@8 / MRR**。

| 切块与嵌入 | Dense | BM25 | Hybrid | 原始结果 |
|---|---|---|---|---|
| 字符＋标准 | 100% / 0.903 | 55.6% / 0.350 | 100% / 0.565 | [JSON](../../data/v2/retrieval_src.json) |
| 字符＋Flash | 94.4% / 0.778 | 55.6% / 0.350 | 94.4% / 0.524 | [JSON](../../data/v2/retrieval_src_flash.json) |
| AST＋标准 | 100% / 0.856 | 55.6% / 0.380 | 100% / 0.743 | [JSON](../../data/v2/retrieval_src_ast.json) |
| AST＋Flash | 100% / 0.722 | 55.6% / 0.380 | 100% / 0.566 | [JSON](../../data/v2/retrieval_src_ast_flash.json) |
| 字符＋标准＋重排 | 100% / 1.000 | 66.7% / 0.667 | 100% / 1.000 | [JSON](../../data/v2/retrieval_src_rerank.json) |

标准嵌入的 Dense 排名优于 Flash；重排方案的 Dense、Hybrid 均把预期文件排到第一位。但重排同时把 Dense/BM25 候选从 8 扩到 24，再输出 8 条，收益来自“扩大候选＋重排”的组合。

旧 BM25 正则只保留 ASCII 字母、数字和下划线，纯中文查询被切空；全零分仍返回固定代码块，RRF 又把这些块混进 Dense 排序。因此，旧 Hybrid 表现差不能直接解释为混合检索方法无效，AST 的差异也混有全零分排序的影响。

## 3. 中文分词修复后的检索复测

在排除考题文件的另一套干净索引上，用同一批 **75 个块和向量**对比旧分词与汉字单字分词，只重建 BM25。该索引不同于上表，不能跨表归因。

| 指标 | 旧分词 | 汉字单字分词 |
|---|---:|---:|
| Dense Hit@8 / MRR | 18/18 / 0.944 | 18/18 / 0.944 |
| BM25 Hit@8 / MRR | 11/18 / 0.462 | 17/18 / 0.458 |
| Hybrid Hit@8 / MRR | 18/18 / 0.838 | 18/18 / 0.935 |

中文题终于能被 BM25 命中，但总体 MRR 没有提高：单字匹配也增加了其他题型的噪声。Hybrid 接近 Dense，仍未超过它。此后又修正了“无共同词也返回结果”和 RRF 去重、候选数量，这些后续改动尚未重测。

证据：[旧分词](../../data/v2/retrieval_clean_oldtok.json) · [汉字单字分词](../../data/v2/retrieval_clean_cjk.json) · [BM25 实现](../../src/rag/bm25.py)。

以下保留首次运行结果。四组域内误伤均为 **3/40**；阈值只显示四位小数，精确值见 JSON。

| 切块与嵌入 | ROC-AUC | 阈值 | 域外拦截 /50 | 原始结果 |
|---|---:|---:|---:|---|
| 字符＋标准 | 0.8015 | 0.8870 | 28 | [JSON](../../data/v2/soft_fuse_src.json) |
| 字符＋Flash | 0.7435 | 1.1008 | 24 | [JSON](../../data/v2/soft_fuse_src_flash.json) |
| AST＋标准 | 0.7985 | 0.8066 | 32 | [JSON](../../data/v2/soft_fuse_src_ast.json) |
| AST＋Flash | 0.6635 | 1.0816 | 17 | [JSON](../../data/v2/soft_fuse_src_ast_flash.json) |

审计发现，部分最近代码块来自存放题目和标准答案的四个文件：`soft_fuse_dataset.py`、`e2e_manifest.py`、`rag_dataset.py`、`rewriter_noisy_dataset.py`。题面可能直接影响检索距离，因此需要排除这些块再测；评测脚本本身仍可作为源码知识保留。

## 5. 排除考题文件与重新标定

**第一次复现停止。** 完成干净索引派生后，字符＋标准旧结果复现出现 2/90 题最近来源变化，最大距离差 0.105506，AUC 从 0.8015 变为 0.7980，未满足验收要求。因此该轮没有继续跑其余旧索引或四套干净标定。另一次完整性核对发现 clean90 评分等产物变化，未查明来源；停止状态和差异均保留在原始记录。

**随后重新建立基线。** 在临时副本还原六题七处历史名称，解释性核对达到最近来源 90/90 一致、最大距离差 0.000365；正式八次运行仍保持 RepoAgent 题面原样，分别测四套原索引与干净索引。以下均为这轮新结果，不用首次历史值拼接对照：

| 切块与嵌入 | AUC：原 → 干净 | 域外拦截 /50：原 → 干净 | 干净阈值 | 最近来源为考题文件 /90：原 → 干净 |
|---|---:|---:|---:|---:|
| 字符＋标准 | 0.7980 → 0.8515 | 28 → 33 | 0.905347 | 33 → 0 |
| AST＋标准 | 0.8010 → 0.8685 | 32 → 36 | 0.885177 | 38 → 0 |
| 字符＋Flash | 0.7440 → 0.8630 | 24 → 35 | 1.166496 | 49 → 0 |
| AST＋Flash | 0.6655 → 0.8305 | 18 → 33 | 1.167724 | 48 → 0 |

八组域内误伤均为 **3/40**。干净 AST＋标准拦住 36/50，其中明显通用题 28/28、术语接近题 6/12、误导边界题 2/10；难点仍是用词像本仓库、实际不需查库的问题。该轮保护文件 387/387 哈希一致，旧索引在临时副本中打开；9 次评估共 810 条查询，没有重建或重新嵌入索引。

字符＋标准的干净阈值为 0.905346930。此次单位向量使用平方 L2 距离，`d² = 2 − 2cosθ`，相当于余弦相似度低于约 0.5473 时拦截。不同模型和索引须分别标定，三月的 1.12 不能直接沿用。

## 6. 结论

1. 在线检索保留标准嵌入的 Dense；Hybrid 和重排目前作为实验对照。重排尚无完整延迟、费用对照，中文分词后续修复也需要复测。
2. 软熔断可作检索后的兜底，不能代替检索前的路由；当前默认关闭。四套干净索引的离线推荐阈值不代表已经启用。
3. 检索只有 18 题且按文件计分；软熔断在同一批 90 题上选阈值并统计，两者仍需独立题集验证。原始结果、复现失败、新基线分别保存。
